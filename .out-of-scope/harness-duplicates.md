# Skills for what the harness already does

**What:** `status`, `close`, `ticket-shape`, `portfolio`, a decision format: seven rules and skills proposed in one
sitting to replace a paused agent system.

**Why not:** each one repeated something the harness or an existing skill already did (one message with all the
decisions, relaunching a `WAITING` worker, stopping before an irreversible step). Kept: `groom` and four lines in
the card.

**Reopens when:** the same gap was written down three times, or a commitment was lost because of it.
