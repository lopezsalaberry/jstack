# Working with jstack (for agents)

Work repos: copy `templates/AGENTS.md` (the rules card and the settings block) into the repo's `AGENTS.md`, and `templates/CLAUDE.md` (`@AGENTS.md`) next to it. To refresh the card later, `./install.sh --card <file>`.

The skills have a word budget (`tests/test_budget.py`): cut before you add. A rule a command can check belongs in a script, not in prose.

Before committing here, run `make test`.
